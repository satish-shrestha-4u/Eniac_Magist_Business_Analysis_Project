# Data

The original dataset used in this project was provided as part of the WBS Coding School Data Science & AI course.

Large original database dump files are not included in this repository because of GitHub file size limitations.

The analysis was completed using the Magist database, which represents a Brazilian e-commerce marketplace.

## Files

- `magist_schema.sql` — database schema structure

- `magist_schema.pdf` — schema documentation or ER diagram
